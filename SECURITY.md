# Security Policy

## Supported versions

| Version | Supported |
|---------|-----------|
| 1.x     | Yes       |
| 0.x     | No        |

## Reporting a vulnerability

MythicMind reads and evaluates recorded dialogue and simulated encounter data.
It makes no network calls and executes nothing it is given. If you find a
security issue — for example a crash on hostile input, a path traversal in the
loader, or a report that leaks file contents beyond the line it flags — please
report it privately with GitHub's "Report a vulnerability" button on the
Security tab.

We aim to acknowledge reports within 72 hours and to ship a fix or mitigation
in the next patch release. Please do not open a public issue before a fix is
available.
